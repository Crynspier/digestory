# Changelog

## 0.1.0 - 2026-09-20

- Initial release.
- RFC 7616 digest core with MD5, SHA-256, and SHA-512-256 families.
- auth and auth-int support.
- UTF-8 and username hashing support.
- Authentication-Info parsing and rspauth verification.
- Compatibility adapter for Net::HTTP::DigestAuth.
- RFC test vectors, security regressions, malformed-input fuzz smoke tests, and HTTP interoperability tests.
